# Windows でのサイズ・メモリ比較（Electron v1.7.2 / Tauri 版）

計測日: 2026-11-05

## 環境

- Windows 11 Pro 10.0.26200、Intel Core i5-13500、メモリ 32 GB
- Electron 版: インストール済みの v1.7.2（Electron 45）
- Tauri 版: `tauri` ブランチ（Electron 撤去後）を `tauri build --bundles msi` でビルドしたもの（署名なし）。WebView2 ランタイム 156.0.4314.58

## サイズ

| | Electron v1.7.2 | Tauri 版 |
|---|---:|---:|
| インストーラ | 169.7 MiB（NSIS .exe） | 10.0 MiB（.msi） |
| インストール後 | 578.7 MB（115 ファイル） | 12.7 MB（exe 1 ファイル） |
| アップデートのダウンロード | 169.7 MiB | 10.0 MiB |

- Electron 版の内訳: `AI-Browser.exe` 238.3 MB（Chromium を内蔵）、`resources/` 221.8 MB、`locales/` 48.8 MB ほか
- Tauri 版は UI もすべて exe に埋め込まれる。描画には OS の WebView2 ランタイム（870.8 MB）を使うが、
  Windows 11 には最初から入っていて Edge などと共有するため、アプリのサイズには含めていない

## メモリ

10 個の AI サービスをすべて読み込んだ状態（ターミナルは未使用）。起動して 120 秒待ってから 10 秒おきに 6 回測った平均。
起動したプロセスとその子孫（Tauri 版は WebView2 のプロセス群を含む）の合計で、Electron 版と Tauri 版を交互に 2 回ずつ測った。

| | Electron v1.7.2（1 回目 / 2 回目） | Tauri 版（1 回目 / 2 回目） |
|---|---:|---:|
| プライベートワーキングセット（タスクマネージャーの「メモリ」） | 2,050 / 2,078 MB | 2,158 / 2,149 MB |
| ワーキングセット | 4,008 / 4,055 MB | 3,681 / 3,667 MB |
| Private Bytes（コミット） | 2,407 / 2,417 MB | 2,888 / 2,869 MB |
| プロセス数 | 20 | 23 |

プライベートワーキングセットの内訳（2 回目）:

| 種類 | Electron v1.7.2 | Tauri 版 |
|---|---:|---:|
| レンダラー（AI サイトと UI） | 15 個 / 1,741 MB | 16 個 / 1,822 MB |
| アプリ本体 | 190 MB（Node.js + ブラウザプロセス） | 6 MB（ai-browser.exe）+ 145 MB（WebView2 のブラウザプロセス） |
| GPU | 82 MB | 118 MB |
| その他（utility / crashpad） | 48 MB | 44 MB |

## まとめ

- **サイズは大幅に小さくなる。** インストーラは約 1/17、インストール後は約 1/45、更新のダウンロードも 170 MB から 10 MB になる
- **メモリはほぼ変わらない（Tauri 版が 4% ほど多い）。** 約 85% は AI サイトを表示するレンダラーが使っており、
  どちらも Chromium 系のエンジンで同じサイトを開いているため差が出ない。アプリ本体は Tauri 版の方が 40 MB ほど小さいが、
  GPU プロセスとレンダラーがやや多い
- 比較の条件は完全には揃っていない。ログイン状態や表示中のページ（Electron 版と Tauri 版で WebView のデータ領域が別）、
  Chromium のバージョン（Electron 45 と WebView2 156）、ウィンドウの大きさやエディタの分割数が異なる
